## 1. 功能概述 (Feature Overview)

### 1.1 业务流程描述

乘客管理功能允许用户在12306账号下管理常用乘车人信息，便于快速预订车票：

```
登录账号 → 进入乘车人管理 → 查看乘车人列表 → 添加/编辑/删除乘车人 → 为乘车人预订车票
```

**流程详解**：

1. **乘车人列表查看**
   - 用户进入"个人中心 > 常用信息管理 > 乘车人"页面
   - 系统展示所有已添加的乘车人列表
   - 显示每个乘车人的基本信息（姓名、证件类型、证件号部分、手机号、核验状态）

2. **添加乘车人**
   - 用户点击"添加"按钮
   - 跳转到添加乘车人表单页面
   - 填写必填信息：证件类型、姓名、证件号码、手机号、优惠(待)类型
   - 提交后系统进行身份核验（24小时内）

3. **编辑乘车人**
   - 用户点击某个乘车人的"修改"图标
   - 跳转到编辑页面
   - **仅可修改**：手机号码和优惠(待)类型
   - 证件信息、姓名等核心信息不可修改

4. **删除乘车人**
   - 用户点击某个乘车人的"删除"图标
   - 系统弹出确认对话框
   - 确认后删除该乘车人
   - 账号本人不可删除

5. **乘车人查询**
   - 用户可通过姓名搜索乘车人
   - 支持模糊查询
   - 支持批量删除功能

### 1.2 子功能列表

#### 1.2.1 乘车人列表展示
- 表格化展示所有乘车人
- 显示字段：序号、姓名、证件类型、证件号码（脱敏）、手机号（脱敏）、核验状态、操作
- 支持复选框选择（用于批量删除）
- 账号本人（序号1）复选框禁用，不可删除

#### 1.2.2 添加乘车人子功能
- **基本信息**：
  - 证件类型（下拉选择，8种证件）
  - 姓名（文本输入，必填）
  - 证件号码（文本输入，必填，身份核验用）
- **联系方式**：
  - 国家/地区代码（默认+86）
  - 手机号码（文本输入，用于接收服务信息）
- **附加信息**：
  - 优惠(待)类型（下拉选择，4种类型：成人、儿童、学生、残疾军人，必填）

#### 1.2.3 编辑乘车人子功能
- **可编辑字段**：
  - 手机号码
  - 优惠(待)类型
- **只读字段**：
  - 证件类型
  - 姓名
  - 证件号码
  - 国家/地区
  - 添加日期
  - 核验状态

#### 1.2.4 删除乘车人子功能
- 单个删除（点击删除图标）
- 批量删除（勾选多个后点击批量删除按钮）
- 删除确认机制
- 账号本人不可删除

#### 1.2.5 查询与筛选
- 姓名模糊搜索
- 查询结果实时更新列表

### 1.3 功能边界

**支持的功能**：
- ✅ 查看所有已添加乘车人
- ✅ 添加新乘车人（支持8种证件类型）
- ✅ 编辑乘车人联系方式和票种类型
- ✅ 删除非本人乘车人
- ✅ 批量删除功能
- ✅ 按姓名查询乘车人
- ✅ 身份核验状态展示
- ✅ 一个账号管理多个乘车人

**不支持的功能**：
- ❌ 编辑证件类型和证件号码（核心身份信息不可修改）
- ❌ 删除账号本人信息
- ❌ 直接修改姓名
- ❌ 修改添加日期
- ❌ 手动修改核验状态

### 1.4 前置条件

- **必须登录**：所有乘车人管理功能均需用户登录
- **账号实名认证**：至少有一个已实名认证的账号（本人）
- **网络环境**：稳定的网络连接
- **浏览器要求**：支持现代浏览器（Chrome、Edge、Firefox等）
- **证件信息准确**：添加的乘车人信息必须真实有效，用于身份核验

### 1.5 业务规则

1. **身份核验规则**
   - 添加乘车人后24小时内系统自动核验
   - 核验状态：已通过、待核验、未通过
   - 未通过核验的需持证件到车站办理

2. **数量限制**
   - 一个账号最多可添加15个常用联系人（包括本人）

3. **信息安全**
   - 证件号码脱敏显示（仅显示前4位和后3位）
   - 手机号脱敏显示（仅显示前3位、国家代码和后4位）

4. **修改限制**
   - 核心身份信息（姓名、证件类型、证件号）添加后不可修改
   - 如需修改核心信息，需删除后重新添加

## 2. 优先级 (MoSCoW评级)

### 2.1 Must Have（核心功能）

| 功能点 | 评级依据 |
|--------|----------|
| 查看乘车人列表 | 核心入口功能，用户必须能看到已添加的乘车人 |
| 添加乘车人 | 必须功能，没有乘车人无法为他人预订车票 |
| 填写证件信息 | 实名制要求，必须提供真实有效证件信息 |
| 选择证件类型 | 支持不同用户群体（内地、港澳台、外籍） |
| 填写姓名和证件号 | 实名制核心字段，缺失则无法完成添加 |
| 选择旅客类型 | 确定票价和优惠政策的关键信息 |
| 身份核验 | 铁路实名制要求，未通过核验的旅客无法购票 |
| 删除乘车人 | 用户需要能删除不再使用的乘车人信息 |

### 2.2 Should Have（重要功能）

| 功能点 | 评级依据 |
|--------|----------|
| 编辑乘车人信息 | 重要功能，用户需要更新联系方式 |
| 手机号码填写 | 重要但非强制，用于接收服务信息和紧急联系 |
| 查询功能 | 当乘车人较多时提升查找效率 |
| 核验状态展示 | 告知用户乘车人是否可用于购票 |
| 信息脱敏显示 | 保护用户隐私，提升安全性 |
| 添加日期显示 | 帮助用户了解乘车人添加时间 |
| 本人不可删除限制 | 防止误操作，保护账号主体信息 |

### 2.3 Could Have（增强功能）

| 功能点 | 评级依据 |
|--------|----------|
| 批量删除 | 提升操作效率，但使用频率相对较低 |
| 姓名填写规则提示 | 帮助用户正确填写，减少错误 |
| 温馨提示信息 | 告知核验规则，用户体验增强 |
| 多证件类型支持 | 支持港澳台、外籍旅客，覆盖更广用户群 |
| 儿童/学生/残疾军人类型 | 特殊票价支持，但使用频率较低 |
| 国家/地区代码选择 | 支持国际手机号，但多数用户使用+86 |

### 2.4 Won't Have（当前版本不考虑）

| 功能点 | 评级依据 |
|--------|----------|
| 修改证件信息 | 安全和合规性考虑，核心身份信息不允许修改 |
| 删除本人信息 | 账号主体信息，不允许删除 |
| 自动填充功能 | 技术复杂度高，非核心需求 |
| 乘车人分组管理 | 功能增强但非必须，当前版本不考虑 |
| 导入导出功能 | 使用场景有限，优先级低 |

## 3. 用户故事 (User Stories)

### 3.1 查看乘车人列表

#### US-01: 查看所有乘车人

```
As a 已登录用户
I want to 查看我添加的所有常用乘车人列表
So that 我可以了解当前可用的乘车人，并选择需要修改或删除的对象

验收条件：
- 能进入"个人中心 > 常用信息管理 > 乘车人"页面
- 页面以表格形式展示所有乘车人
- 每行显示：序号、姓名、证件类型、证件号（脱敏）、手机号（脱敏）、核验状态、操作
- 第一个乘车人为账号本人，复选框禁用
- 其他乘车人显示"修改"和"删除"图标
```

#### US-02: 查询特定乘车人

```
As a 已登录用户
I want to 通过姓名搜索乘车人
So that 当乘车人较多时我可以快速找到目标对象

验收条件：
- 页面顶部有搜索框，提示"请输入乘客姓名"
- 输入姓名后点击"查询"按钮
- 列表实时更新，只显示匹配的乘车人
- 支持模糊匹配
- 可点击清除按钮重置查询条件
```

### 3.2 添加乘车人

#### US-03: 添加成人乘车人 - 居民身份证

```
As a 已登录用户
I want to 添加一个使用居民身份证的成人乘车人
So that 我可以为家人或朋友预订车票

验收条件：
- 点击"添加"按钮后跳转到添加页面
- 默认证件类型为"居民身份证"
- 默认旅客类型为"成人"
- 可填写姓名、证件号码、手机号
- 所有必填项（*标记）填写完整后可点击"保存"
- 保存后返回列表页，新乘车人出现在列表中
- 核验状态显示为"待核验"或"已通过"
```

#### US-04: 添加儿童乘车人

```
As a 已登录用户
I want to 添加一个儿童乘车人
So that 我可以为孩子预订儿童票

验收条件：
- 在添加页面点击"优惠(待)类型"下拉框
- 能选择"儿童"选项
- 提交后该乘车人标记为儿童类型
- 预订车票时自动应用儿童票价
```

#### US-05: 添加学生乘车人

```
As a 已登录用户
I want to 添加一个学生乘车人
So that 我可以享受学生票优惠

验收条件：
- 在添加页面点击"优惠(待)类型"下拉框
- 能选择"学生"选项
- 提交后该乘车人标记为学生类型
- 预订车票时可选择学生票
```

#### US-06: 选择不同证件类型

```
As a 港澳台或外籍用户
I want to 选择适合我的证件类型
So that 我可以使用我持有的有效证件添加乘车人

验收条件：
- 点击"证件类型"下拉框显示8种选项：
  1. 居民身份证
  2. 港澳居民居住证
  3. 台湾居民居住证
  4. 外国人永久居留身份证
  5. 港澳居民来往内地通行证
  6. 台湾居民来往大陆通行证
  7. 中国护照
  8. 外国护照
- 选择不同证件类型后，证件号码输入框验证规则相应变化
```

### 3.3 编辑乘车人

#### US-07: 编辑乘车人联系方式

```
As a 已登录用户
I want to 修改乘车人的手机号码
So that 我可以更新联系方式以接收最新的服务信息

验收条件：
- 点击乘车人行的"修改"图标
- 跳转到编辑页面
- 手机号码输入框可编辑
- 优惠(待)类型下拉框可更改
- 证件类型、姓名、证件号码、国家/地区为只读显示
- 显示添加日期和核验状态（只读）
- 点击"保存"后更新成功，返回列表页
```

#### US-08: 尝试修改不可编辑字段

```
As a 已登录用户
I want to 了解哪些字段不可修改
So that 我知道如需更改核心信息需要删除重新添加

验收条件：
- 进入编辑页面后，以下字段为只读显示（非输入框）：
  - 证件类型
  - 姓名
  - 证件号码
  - 国家/地区
  - 添加日期
  - 核验状态
- 用户无法点击或修改这些字段
```

### 3.4 删除乘车人

#### US-09: 删除单个乘车人

```
As a 已登录用户
I want to 删除一个不再使用的乘车人
So that 我可以清理列表，避免误选

验收条件：
- 点击非本人乘车人行的"删除"图标
- 弹出确认对话框，提示"确认删除该乘车人吗？"
- 点击"确定"后乘车人从列表中移除
- 点击"取消"后对话框关闭，乘车人保留
- 账号本人（序号1）无"删除"图标
```

#### US-10: 批量删除乘车人

```
As a 已登录用户
I want to 一次删除多个不再使用的乘车人
So that 我可以快速清理列表

验收条件：
- 勾选多个非本人乘车人的复选框
- 点击"批量删除"按钮
- 弹出确认对话框，显示将要删除的乘车人数量
- 确认后所有选中的乘车人被删除
- 本人复选框为禁用状态，无法勾选
```

### 3.5 异常流程

#### US-11: 添加时必填项为空

```
As a 已登录用户
I want to 看到明确的表单验证提示
So that 我知道哪些信息必须填写

验收条件：
- 必填项带有*号标记
- 未填写必填项时点击"保存"
- 系统提示"请填写XX"或高亮未填写的字段
- 不跳转页面，停留在表单页等待用户补充
```

#### US-12: 证件号码格式错误

```
As a 已登录用户
I want to 收到证件号码格式错误的提示
So that 我可以修正输入

验收条件：
- 输入不符合证件类型规则的证件号
- 点击"保存"后系统提示"证件号码格式错误，请检查"
- 提示证件号码的正确格式要求
- 用户可修改后重新提交
```

#### US-13: 身份核验未通过

```
As a 已登录用户
I want to 知道乘车人身份核验未通过
So that 我可以采取相应措施

验收条件：
- 添加乘车人24小时后，核验状态显示为"待核验"或"未通过"
- 未通过核验的乘车人在预订时无法选择
- 页面提示"如旅客身份信息未能在添加后的24小时内通过核验，请乘车人持有效身份证原件到车站办理身份核验"
```
