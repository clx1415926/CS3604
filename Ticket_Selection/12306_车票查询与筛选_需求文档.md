## 1. 功能概述 (Feature Overview)

### 1.1 业务流程描述

车票查询与筛选功能是用户购票流程的第一步，通过输入出行信息并使用筛选条件，快速找到符合需求的车次：

```
输入查询条件 → 点击查询 → 显示车次列表 → 使用筛选功能 → 选择合适车次 → 预订
```

**核心流程**：

1. **输入查询条件**
   - 选择单程/往返
   - 输入出发地
   - 输入目的地  
   - 选择出发日期
   - 选择票种（普通/学生）
   - 点击"查询"按钮

2. **查看车次列表**
   - 系统展示所有符合条件的车次
   - 按出发时间默认排序
   - 显示车次号、出发/到达站、时间、历时、余票信息
   - 显示各席别票价和余票数量

3. **使用筛选功能**
   - **发车时间**：选择时间段（00:00-06:00等）
   - **车次类型**：GC-高铁/城际、D-动车、Z-直达、T-特快、K-快速等
   - **出发车站**：选择具体出发站（如北京、北京南等）
   - **到达车站**：选择具体到达站
   - **车次席别**：选择席别类型筛选
   - 点击"筛选"按钮应用条件

4. **快速日期切换**
   - 点击日期快捷按钮切换查询日期
   - 系统自动重新查询该日期车次

### 1.3 功能边界

**包含的功能**：
- ✅ 单程车票查询（往返功能不在本次范围）
- ✅ 出发地/目的地输入与联想
- ✅ 出发日期选择（30天预售期内）
- ✅ 普通票/学生票切换
- ✅ 车次列表展示（车次号、站点、时间、余票）
- ✅ 发车时间筛选（5个时间段）
- ✅ 车次类型筛选（高铁、动车、直达等）
- ✅ 出发/到达车站筛选
- ✅ 席别筛选
- ✅ 日期快捷切换
- ✅ 车次排序（按出发/到达时间）

**不包含的功能**：
- ❌ 往返车票查询（单独功能模块）
- ❌ 中转换乘查询（单独功能模块）
- ❌ 候补购票功能（在订单管理中）
- ❌ 车次详情查看（点击车次号）
- ❌ 价格走势分析
- ❌ 智能推荐车次

### 1.4 前置条件

- 用户已访问12306车票查询页面
- 系统有当前可查询的车次数据
- 出发地和目的地城市有铁路连接
- 查询日期在30天预售期内

### 1.5 业务规则

**查询规则**：

1. **预售期限制**
   - 最多可查询30天内的车次
   - 当日车票截止时间：开车前30分钟

2. **站点输入规则**
   - 支持城市名和车站名
   - 同一城市多个车站时自动展开
   - 支持拼音首字母快速输入

3. **学生票规则**
   - 学生票价为普通票价的75%
   - 仅限特定席别（硬座、硬卧、二等座）
   - 需持有学生证和学生优惠卡

**筛选规则**：

1. **多条件筛选**
   - 所有筛选条件采用"与"逻辑
   - 勾选同类型多个选项采用"或"逻辑
   - 例如：高铁 OR 动车 AND 一等座有余票

2. **筛选即时生效**
   - 勾选筛选条件后车次数量实时变化
   - 点击"筛选"按钮后列表立即刷新
   - 筛选不触发新的后端查询

3. **筛选条件持久化**
   - 切换日期后筛选条件保持
   - 刷新页面后筛选条件重置

## 3. 用户故事 (User Stories)

### 3.1 查询相关

#### US-01: 输入出发地和目的地

```
As a 计划出行的用户
I want to 输入出发地和目的地
So that 我可以查询两地之间的车次

验收条件：
- 出发地输入框支持中文输入
- 输入时显示城市/车站联想列表
- 点击联想项自动填充
- 出发地和目的地不能相同
- 显示输入提示"请输入或选择出发站"
```

#### US-02: 选择出发日期

```
As a 计划出行的用户
I want to 选择出发日期
So that 我可以查询指定日期的车次

验收条件：
- 点击日期输入框弹出日历控件
- 日历显示30天预售期
- 过去日期显示为灰色不可选
- 选择日期后日历自动关闭
- 输入框显示选中日期（格式：2025-11-17）
```

#### US-03: 查询车次

```
As a 已输入查询条件的用户
I want to 点击查询按钮
So that 我可以看到符合条件的车次列表

验收条件：
- 出发地、目的地、日期必填
- 点击"查询"按钮后显示加载动画
- 2-3秒内返回查询结果
- 显示车次总数"共X个车次"
- 车次按出发时间默认排序
- 无车次时显示"未查询到符合条件的车次"
```

#### US-04: 查看车次列表信息

```
As a 查询到车次的用户
I want to 查看车次详细信息
So that 我可以选择合适的车次

验收条件：
- 每个车次显示：车次号、出发站、到达站
- 显示出发时间、到达时间、历时
- 显示各席别名称和余票数量
- 有余票的席别显示"有"或具体数量
- 无余票显示"--"或"无"
- 显示蓝色"预订"按钮
```

###  3.2 筛选相关

#### US-05: 按车次类型筛选

```
As a 查询到大量车次的用户
I want to 筛选特定类型的车次（如高铁）
So that 我可以快速找到符合出行偏好的车次

验收条件：
- 筛选区显示8种车次类型复选框
- 类型包括：GC-高铁/城际、D-动车、Z-直达、T-特快、K-快速、其他、复兴号、智能动车组
- 勾选后车次数量实时更新
- 可同时勾选多个类型
- 点击"筛选"按钮应用条件
- 显示筛选后的车次总数
```

#### US-06: 按发车时间筛选

```
As a 对出发时间有要求的用户
I want to 选择发车时间段
So that 我只看到符合我时间安排的车次

验收条件：
- 发车时间下拉框有5个选项
- 选项：00:00--24:00（全部）、00:00--06:00、06:00--12:00、12:00--18:00、18:00--24:00
- 默认选中"00:00--24:00"
- 选择后点击"筛选"应用
- 只显示该时间段内发车的车次
```

#### US-07: 按出发/到达车站筛选

```
As a 在同城有多个车站的情况下出行的用户
I want to 选择具体的出发或到达车站
So that 我只看到从指定车站出发/到达的车次

验收条件：
- 出发车站下拉框显示所有起始站选项
- 到达车站下拉框显示所有终点站选项
- 默认显示"全部"
- 可多选车站
- 点击"筛选"应用条件
- 只显示符合车站条件的车次
```

#### US-08: 按席别筛选

```
As a 对座位类型有要求的用户
I want to 筛选有特定席别余票的车次
So that 我只看到能买到我需要的座位类型的车次

验收条件：
- 席别筛选显示所有可用席别
- 包括：一等座、二等座、商务座、软卧、硬卧等
- 可多选席别
- 点击"筛选"应用条件
- 只显示这些席别有余票的车次
```

### 3.3 便捷操作

#### US-09: 快速切换日期

```
As a 想对比不同日期车次的用户
I want to 快速切换查询日期
So that 我不需要重新打开日历选择

验收条件：
- 查询表单下方显示15天日期快捷按钮
- 当前选中日期高亮显示
- 点击其他日期按钮立即查询该日期车次
- 筛选条件保持不变
```

#### US-10: 出发地目的地互换

```
As a 需要查询往返程的用户
I want to 快速交换出发地和目的地
So that 我不需要手动重新输入

验收条件：
- 出发地和目的地之间有交换按钮（箭头图标）
- 点击按钮后两者内容互换
- 需要重新点击"查询"按钮
```

#### US-11: 车次排序

```
As a 需要特定到达时间的用户
I want to 按到达时间排序车次
So that 我可以找到最早/最晚到达的车次

验收条件：
- 出发时间和到达时间列头可点击
- 点击后按该时间升序/降序排列
- 显示排序箭头指示方向
- 默认按出发时间升序
```

### 3.4 异常流程

#### US-12: 查询条件缺失

```
As a 未填写完整查询条件的用户
I want to 收到明确的提示
So that 我知道需要补充哪些信息

验收条件：
- 出发地为空时提示"请输入出发地"
- 目的地为空时提示"请输入目的地"
- 日期为空时提示"请选择出发日期"
- 提示以红色文字显示在对应输入框下方
```

#### US-13: 无符合条件的车次

```
As a 查询到无车次的用户
I want to 看到友好的提示信息
So that 我知道如何调整查询条件

验收条件：
- 车次列表区域显示"未查询到符合条件的车次"
- 提供建议："请尝试更换日期或放宽筛选条件"
- 显示放松筛选的快捷按钮
```

## 5. 验收标准 (Acceptance Criteria)

采用 **Gherkin语言** (Given-When-Then格式)。

### 5.1 基本查询功能

```gherkin
Feature: 车票查询

Scenario: 成功查询车次 - 正常流程
  Given 用户在车票查询页面
  When 用户输入出发地"北京"
  And 用户输入目的地"上海"
  And 用户选择出发日期"2025-11-17"
  And 用户点击"查询"按钮
  Then 页面显示车次列表
  And 显示"共X个车次"
  And 列表包含车次号、站点、时间、余票信息
  And 有余票的车次显示"预订"按钮

Scenario: 查询条件验证 - 出发地为空
  Given 用户在车票查询页面
  When 用户不输入出发地
  And 用户输入目的地"上海"
  And 用户点击"查询"按钮
  Then 出发地输入框显示红色边框
  And 显示提示"请输入出发地"
  And 不发送查询请求

Scenario: 查询条件验证 - 出发地和目的地相同
  Given 用户在车票查询页面
  When 用户输入出发地"北京"
  And 用户输入目的地"北京"
  And 用户点击"查询"按钮
  Then 显示错误提示"出发地和目的地不能相同"
  And 不发送查询请求

Scenario: 日期选择 - 点击日历控件
  Given 用户在车票查询页面
  When 用户点击出发日输入框
  Then 弹出日历控件
  And 日历显示本月和下月
  And 今天日期高亮显示
  And 过去日期显示为灰色不可点击

Scenario: 日期选择 - 选择未来日期
  Given 用户打开了日历控件
  When 用户点击某个未来日期（如11月20日）
  Then 日历自动关闭
  And 出发日输入框显示"2025-11-20"
  And 日期按钮高亮"11-20"

Scenario: 出发地目的地互换
  Given 用户输入出发地"北京"
  And 用户输入目的地"上海"
  When 用户点击互换按钮
  Then 出发地变为"上海"
  And 目的地变为"北京"
  And 需要重新点击查询

Scenario: 普通票/学生票切换
  Given 用户在车票查询页面
  When 用户选择"学生票"
  And 用户点击"查询"按钮
  Then 查询学生票车次
  And 票价显示为普通票的75%
```
