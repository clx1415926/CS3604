# 车票查询页与首页样式差异排查

## 已修复的问题

### 1. CSS加载顺序调整 ✅

**修改前：**
```html
<link rel="stylesheet" href="/assets/iconfont.css">
<link rel="stylesheet" href="/src/index.css">
<link rel="stylesheet" href="/12306_homepage/www.12306.cn/index/css/index_y_v50003.css">
```

**修改后：**
```html
<link rel="stylesheet" href="/assets/iconfont.css">
<link rel="stylesheet" href="/12306_homepage/www.12306.cn/index/css/index_y_v50003.css">
<link rel="stylesheet" href="/src/index.css">  <!-- 最后加载，优先级最高 -->
```

**原因：** CSS文件按顺序加载，后面的会覆盖前面的。将车票查询页的CSS放在最后，确保样式不被覆盖。

### 2. 增强CSS优先级 ✅

添加了更多 `!important` 声明，确保关键样式不被其他CSS覆盖：

```css
/* 背景透明 */
.header .wrapper,
.header-con,
.header-right { 
  background: transparent !important; 
  box-shadow: none !important; 
  border: none !important; 
}

/* body背景色 */
body { 
  background-color: #f5f5f5 !important; 
}
```

## 可能的样式差异原因

### 1. 外部CSS文件干扰
`/12306_homepage/www.12306.cn/index/css/index_y_v50003.css` 可能包含覆盖样式。

**解决方案：**
- ✅ 调整CSS加载顺序（已完成）
- ✅ 使用 `!important` 提高优先级（已完成）

### 2. 浏览器缓存
旧的CSS可能被缓存。

**解决方案：**
- 按 `Ctrl + Shift + R` (Windows) 强制刷新
- 或清除浏览器缓存

### 3. Vite开发服务器缓存
Vite可能缓存了旧的CSS。

**解决方案：**
```bash
# 停止服务器 (Ctrl+C)
# 删除缓存
rm -rf node_modules/.vite
# 重新启动
npm run dev
```

### 4. React根元素样式干扰
`#root` 元素可能有默认样式。

**已处理：**
```css
#root {
    min-height: 100vh;
    display: flex;
    flex-direction: column;
}
```

## 如果样式仍然不一致

### 方法1：使用浏览器开发者工具检查

1. 按 `F12` 打开开发者工具
2. 选择"Elements"标签
3. 点击左上角的选择工具
4. 点击页面上样式不对的元素
5. 在右侧"Styles"面板查看：
   - 哪些CSS规则被应用
   - 哪些规则被划掉（被覆盖）
   - 规则来自哪个CSS文件

### 方法2：对比两个页面

打开两个浏览器窗口：
- 首页：`http://localhost:8099/`
- 车票查询：`http://localhost:5173/`

使用开发者工具检查相同元素的样式差异。

### 方法3：临时禁用外部CSS

临时注释掉外部CSS，看是否是它导致的问题：
```html
<!-- <link rel="stylesheet" href="/12306_homepage/www.12306.cn/index/css/index_y_v50003.css"> -->
```

## 常见问题

### Q: 头部背景不透明？
A: 检查是否有其他CSS设置了背景色，使用开发者工具查看实际应用的样式。

### Q: 颜色不对？
A: 确认 `/src/index.css` 是最后加载的CSS文件，并且使用了 `!important`。

### Q: 字体大小不对？
A: 检查是否继承了其他元素的字体大小，确认CSS选择器的优先级。

### Q: Logo图标不显示？
A: 检查：
- 图片路径：`/assets/top_pic.png`
- 图片文件是否存在
- 浏览器控制台是否有404错误
