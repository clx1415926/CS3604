## 1. 功能概述 (Feature Overview)

### 1.1 业务流程描述

登录与注册功能是用户进入12306系统的入口，提供两种登录方式和完整的账号注册流程：

```
未注册用户 → 注册页面 → 填写账户信息 → 身份核验 → 手机验证 → 注册成功 → 登录

已注册用户 → 登录页面 → 账号登录/扫码登录 → 系统首页
```

**核心流程详解**：

**A. 注册流程**

1. **进入注册页面**
   - 用户从登录页点击"注册12306账号"链接
   - 或从首页点击"注册"按钮
   - 跳转到账户信息填写页面

2. **填写账户信息（第一步）**
   - 设置账号：用户名、登录密码、确认密码
   - 填写身份信息：证件类型、姓名、证件号码
   - 填写附加信息：优惠(待)类型、邮箱（可选）
   - 填写手机号码（必填，用于接收验证码）
   - 勾选《服务条款》和《隐私权政策》同意框

3. **身份核验（系统后台）**
   - 系统调用公安部身份核验接口
   - 验证姓名和证件号码是否匹配
   - 验证手机号是否已注册

4. **手机短信验证（第二步）**
   - 系统向手机号发送6位数字验证码
   - 用户在限定时间内（通常5分钟）输入验证码
   - 支持重新发送验证码（有次数和时间间隔限制）

5. **注册完成**
   - 账号创建成功
   - 自动跳转到登录页或直接登录进入系统

**B. 登录流程**

**方式1：账号登录**
1. 用户选择"账号登录"标签
2. 输入用户名/邮箱/手机号
3. 输入登录密码
4. 点击"立即登录"按钮
5. 系统验证通过后跳转到个人中心或车票查询页

**方式2：扫码登录**
1. 用户选择"扫码登录"标签
2. 系统生成登录二维码（有效期约3分钟）
3. 用户使用12306 APP扫描二维码
4. 在APP上确认登录
5. 网页端自动完成登录并跳转

### 1.3 功能边界

**包含的功能**：
- ✅ 账号注册（用户名、密码、身份信息、手机号）
- ✅ 账号登录（用户名/邮箱/手机号 + 密码）
- ✅ 扫码登录（二维码扫描）
- ✅ 实名制身份核验（姓名+证件号码）
- ✅ 手机短信验证
- ✅ 忘记密码入口
- ✅ 服务条款同意确认

**不包含的功能**：
- ❌ 密码找回流程（在专门的找回密码页面）
- ❌ 账号注销（在个人信息管理中）
- ❌ 邮箱激活流程
- ❌ 第三方账号登录（微信、QQ等）
- ❌ 人脸识别登录
- ❌ 登录后的权限控制（属于其他模块）

### 1.4 前置条件

**注册前置条件**：
- 用户拥有有效的中华人民共和国身份证件
- 用户拥有本人手机号码且能接收短信
- 用户的身份信息可通过公安部身份核验系统验证
- 用户尚未使用该身份证件或手机号注册过账号

**登录前置条件**：
- 用户已成功注册12306账号
- 账号未被封禁或注销
- （扫码登录）用户已安装12306 APP并登录

### 1.5 业务规则

**注册业务规则**：

1. **用户名规则**
   - 长度：6-30位字符
   - 格式：字母、数字或下划线"_"
   - 必须以字母开头
   - 设置后不可修改
   - 不允许重复

2. **密码规则**
   - 长度：6-20位字符
   - 格式：字母、数字或符号
   - 建议包含大小写字母、数字和符号的组合
   - 密码强度提示（弱/中/强）

3. **证件类型**
   - 居民身份证（默认）
   - 港澳居民来往内地通行证
   - 台湾居民来往大陆通行证
   - 护照
   - 其他有效证件类型

4. **实名制核验**
   - 姓名和证件号码必须真实有效
   - 一个证件号码只能注册一个账号
   - 身份信息提交后需经过公安部核验
   - 核验失败将无法完成注册

5. **手机号验证**
   - 一个手机号最多注册5个账号
   - 验证码有效期5分钟
   - 同一手机号1分钟内只能发送1次验证码
   - 同一手机号1天内最多发送10次验证码

6. **优惠(待)类型**
   - 成人（默认）：普通票价
   - 儿童：儿童票（身高1.2-1.5米）
   - 学生：学生票（需学生证）
   - 残疾军人：军人优待票

**登录业务规则**：

1. **登录限制**
   - 连续5次密码错误将锁定账号30分钟
   - 密码错误3次后需输入图形验证码
   - 异常登录行为（如频繁切换IP）可能触发风控

2. **会话管理**
   - 登录状态默认保持24小时
   - 可选择"记住我"延长至7天
   - 同一账号可在多个设备登录
   - 退出登录清除会话信息

3. **二维码规则**
   - 二维码有效期180秒（3分钟）
   - 过期自动刷新生成新二维码
   - 扫码后需在APP端30秒内确认
   - 二维码只能使用一次

## 2. 优先级 (MoSCoW评级)

### 2.1 Must Have（必须有）

**P0 - 核心功能，系统上线必需**

| 编号 | 功能 | 说明 | 理由 |
|------|------|------|------|
| M-01 | 账号注册（基本信息） | 用户名、密码、姓名、证件号、手机号 | 用户进入系统的前提，实名制要求 |
| M-02 | 身份核验 | 实名制验证（公安部接口） | 国家法律法规强制要求 |
| M-03 | 手机短信验证 | 注册时手机号验证 | 确保账号安全，防止恶意注册 |
| M-04 | 账号登录 | 用户名/手机号+密码登录 | 用户访问系统的基本途径 |
| M-05 | 密码错误提示 | 登录失败时明确提示原因 | 基本的用户体验要求 |
| M-06 | 服务条款确认 | 注册时必须同意服务条款 | 法律合规要求 |

### 2.2 Should Have（应该有）

**P1 - 重要功能，显著提升用户体验**

| 编号 | 功能 | 说明 | 优先级依据 |
|------|------|------|-----------|
| S-01 | 扫码登录 | 使用APP扫描二维码登录 | 提升登录便捷性和安全性 |
| S-02 | 忘记密码入口 | 跳转到密码找回页面 | 常见用户需求 |
| S-03 | 密码强度提示 | 注册时实时提示密码强度 | 引导用户设置安全密码 |
| S-04 | 表单实时验证 | 输入时即时验证格式 | 减少提交后的错误反馈 |
| S-05 | 邮箱填写 | 可选填写邮箱地址 | 提供额外的找回密码途径 |
| S-06 | 验证码倒计时 | 显示重新发送验证码的倒计时 | 清晰的操作引导 |

### 2.3 Could Have（可以有）

**P2 - 有用但非必需的功能**

| 编号 | 功能 | 说明 | 考虑因素 |
|------|------|------|----------|
| C-01 | 记住我 | 保持登录状态7天 | 便利性与安全性的平衡 |
| C-02 | 密码可见切换 | 密码输入框显示/隐藏切换 | 方便用户检查输入 |
| C-03 | 用户名可用性检查 | 实时检查用户名是否已被使用 | 减少提交失败 |
| C-04 | 证件照片上传 | 上传证件照片辅助核验 | 提升核验成功率 |
| C-05 | 注册进度提示 | 显示当前注册步骤 | 增强用户体验 |

### 2.4 Won't Have（暂不实现）

**P3 - 当前版本不考虑的功能**

| 编号 | 功能 | 说明 | 不实现原因 |
|------|------|------|-----------|
| W-01 | 第三方登录 | 微信、QQ、支付宝登录 | 技术复杂度高，安全风险 |
| W-02 | 人脸识别登录 | 使用面部识别进行登录 | 需要额外硬件支持 |
| W-03 | 指纹登录 | 使用指纹进行登录 | 设备兼容性问题 |
| W-04 | 多语言注册 | 支持英文、繁体等多语言 | 当前主要面向中国大陆用户 |
| W-05 | 企业账号注册 | 企业批量注册通道 | 属于单独的企业服务模块 |

## 3. 用户故事 (User Stories)

### 3.1 注册相关

#### US-01: 新用户注册账号

```
As a 首次使用12306的用户
I want to 通过填写个人信息注册账号
So that 我可以开始使用12306购票和相关服务

验收条件：
- 能从登录页或首页进入注册页面
- 注册表单包含所有必填字段（用户名、密码、姓名、证件号、手机号）
- 能选择证件类型和优惠(待)类型
- 能勾选同意服务条款
- 点击"下一步"后进入手机验证环节
```

#### US-02: 填写用户名和密码

```
As a 正在注册的用户
I want to 设置符合规则的用户名和密码
So that 我可以创建一个安全的账号

验收条件：
- 用户名必须6-30位，字母开头，只能包含字母/数字/"_"
- 密码必须6-20位，可包含字母/数字/符号
- 用户名不符合规则时显示错误提示
- 密码强度实时显示（弱/中/强）
- 确认密码与密码不一致时提示错误
- 提示"用户名设置成功后不可修改"
```

#### US-03: 填写身份信息

```
As a 正在注册的用户
I want to 填写真实的身份信息
So that 我的账号可以通过实名制核验

验收条件：
- 能选择8种证件类型之一（默认为居民身份证）
- 姓名输入框支持中文和字母
- 证件号码根据证件类型有不同的格式要求
- 显示提示"用于身份核验，请正确填写"
- 姓名填写规则有详细说明链接
```

#### US-04: 手机号验证

```
As a 正在注册的用户
I want to 通过手机号接收并输入验证码
So that 我可以完成注册并确保账号安全

验收条件：
- 能选择国家/地区代码（+86中国、+852香港、+853澳门、+886台湾）
- 手机号输入框只接受数字
- 填写完所有信息后点击"下一步"发送验证码
- 提示"稍后将向该手机号码发送短信验证码"
- 验证码输入页面有5分钟倒计时
- 支持重新发送验证码（有时间间隔限制）
```

#### US-05: 同意服务条款

```
As a 正在注册的用户
I want to 查看并同意12306的服务条款和隐私政策
So that 我了解使用规则并合法使用服务

验收条件：
- 注册页面底部有服务条款复选框
- 复选框文字："我已阅读并同意遵守"
- 提供《中国铁路客户服务中心网站服务条款》链接（可点击查看）
- 提供《隐私权政策》链接（可点击查看）
- 未勾选时点击"下一步"显示提示"请先同意服务条款"
```

### 3.2 登录相关

#### US-06: 账号登录

```
As a 已注册的用户
I want to 使用用户名和密码登录
So that 我可以访问个人账号和购票

验收条件：
- 登录页面有"账号登录"和"扫码登录"两个标签
- 默认显示"账号登录"标签内容
- 用户名输入框支持：用户名、邮箱、手机号
- 密码输入框默认隐藏密码字符
- 点击"立即登录"后验证账号密码
- 登录成功跳转到首页或车票查询页
- 登录失败显示明确的错误提示
```

#### US-07: 扫码登录

```
As a 已注册且已安装APP的用户
I want to 使用手机APP扫码登录网页端
So that 我可以快速安全地登录而不用输入密码

验收条件：
- 点击"扫码登录"标签显示二维码
- 二维码下方提示"打开12306手机APP 扫描二维码"
- 二维码有3分钟有效期，过期自动刷新
- 扫码后在APP端确认登录
- 网页端自动完成登录并跳转
- 显示扫码登录的优点："更快"、"更安全"
```

#### US-08: 忘记密码

```
As a 忘记密码的用户
I want to 通过找回密码流程重置密码
So that 我可以重新访问我的账号

验收条件：
- 登录页面有"忘记密码？"链接
- 点击后跳转到密码找回页面
- （密码找回流程属于单独页面，不在此详述）
```

### 3.3 异常流程

#### US-09: 用户名已存在

```
As a 正在注册的用户
I want to 在用户名已被使用时收到提示
So that 我可以更换用户名完成注册

验收条件：
- 点击"下一步"后系统检查用户名是否已存在
- 如已存在，显示错误提示"用户名已被使用"
- 用户名输入框标红
- 用户可修改用户名后重新提交
```

#### US-10: 身份核验失败

```
As a 正在注册的用户
I want to 在身份信息验证失败时了解原因
So that 我可以检查并更正信息

验收条件：
- 提交身份信息后系统调用公安部核验接口
- 核验失败显示提示"身份信息验证失败，请检查姓名和证件号码"
- 返回注册页面，保留已填写的其他信息
- 用户可重新填写姓名和证件号码
```

#### US-11: 密码错误次数过多

```
As a 多次输入错误密码的用户
I want to 在账号被临时锁定时收到明确提示
So that 我了解情况并等待解锁

验收条件：
- 密码错误3次后需输入图形验证码
- 密码错误5次后显示"密码错误次数过多，账号已锁定30分钟"
- 锁定期间无法登录
- 显示解锁倒计时
- 提供"忘记密码"链接引导找回密码
```

#### US-12: 手机号已注册多个账号

```
As a 使用同一手机号注册多个账号的用户
I want to 在达到上限时收到提示
So that 我了解限制规则

验收条件：
- 一个手机号最多注册5个账号
- 达到上限后显示提示"该手机号已注册5个账号，无法继续注册"
- 提供客服联系方式
```
