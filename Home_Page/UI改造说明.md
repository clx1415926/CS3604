## 资源文件说明

### 需要手动复制的资源文件

由于路径编码问题，需要手动将以下文件从 `首页_中国铁路12306网站_files` 目录复制到 `Home_Page/frontend/assets/` 目录：

**图片文件：**
- abanner01.jpg（轮播图）
- zgtlwb.png（中国铁路官方微信二维码）
- zgtlwx.png（中国铁路官方微博二维码）
- public.png（12306公众号二维码）
- download.png（铁路12306 APP二维码）
- gongan.png（公安备案图标）
- footer-slh.jpg（适老化无障碍服务图标）
- service01.jpg, service02.jpg, service03.jpg, service04.jpg（服务图标）

**CSS文件：**
- iconfont.css（已创建简化版本，如需完整图标字体，请复制原文件）

### 资源文件复制命令（Windows PowerShell）

```powershell
# 在项目根目录执行
$source = "首页_中国铁路12306网站_files"
$dest = "Home_Page\frontend\assets"

# 复制图片文件
Copy-Item "$source\*.jpg" -Destination $dest -Force
Copy-Item "$source\*.png" -Destination $dest -Force
```
