# 个人中心启动说明

## 问题原因
个人中心无法访问是因为前端或后端服务未启动。

## 端口配置
- **前端服务**: `http://localhost:5176`
- **后端API**: `http://localhost:8083`

## 启动步骤

### 1. 启动后端服务
```powershell
# 打开终端1，进入后端目录
cd D:\HW\CS3601\CS3604\User_Center\backend

# 启动后端服务
node src/server.js
```

**预期输出**:
```
[User_Center] server listening on http://localhost:8083
```

### 2. 启动前端服务
```powershell
# 打开终端2（新终端），进入前端目录
cd D:\HW\CS3601\CS3604\User_Center\frontend

# 安装依赖（首次运行）
npm install

# 启动前端开发服务器
npm run dev
```

**预期输出**:
```
VITE v4.x.x  ready in xxx ms

➜  Local:   http://localhost:5176/
➜  Network: use --host to expose
```

### 3. 访问个人中心
打开浏览器访问：`http://localhost:5176/index.html`

**注意**: 需要先登录才能访问个人中心功能。登录后会自动保存 SESSION_ID 到 localStorage。

## 从首页跳转到个人中心
首页（`http://localhost:8099/`）中的"个人信息"按钮会自动跳转到：
```
http://localhost:5176/index.html?sid=<你的session_id>
```

## 故障排查

### 端口被占用
如果端口 5176 或 8083 被占用：

**查看端口占用**:
```powershell
netstat -ano | findstr "5176"
netstat -ano | findstr "8083"
```

**结束占用进程**:
```powershell
taskkill /PID <进程ID> /F
```

### 依赖未安装
如果前端启动失败，确保安装了依赖：
```powershell
cd User_Center/frontend
npm install
```

### 后端数据文件
后端数据存储在：`User_Center/backend/src/db/data.json`
