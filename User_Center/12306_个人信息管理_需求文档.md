## 1. 功能概述 (Feature Overview)

### 1.1 业务流程描述

个人信息管理功能允许用户查看和编辑账号的基本信息、联系方式和附加信息：

```
登录账号 → 个人中心 → 查看个人信息 → 编辑联系方式/附加信息 → 保存更改
                                ↓
                        （手机号/邮箱修改需跳转专门页面）
```

**流程详解**：

1. **查看个人信息**
   - 用户进入"个人中心 > 个人信息 > 查看个人信息"页面
   - 系统展示用户的所有个人信息
   - 信息分为三个区域：基本信息、联系方式、附加信息

2. **编辑联系方式**
   - 用户点击"编辑"按钮进入联系方式编辑模式
   - 手机号和邮箱无法直接修改，需跳转到专门页面
   - 手机号修改：跳转到"手机核验"页面
   - 邮箱修改：跳转到"安全邮箱"页面
   - 点击"保存"按钮返回查看模式

3. **编辑附加信息**
   - 用户点击"编辑"按钮进入附加信息编辑模式
   - 可直接修改"优惠(待)类型"
   - 选择4种类型之一：成人、儿童、学生、残疾军人
   - 点击"保存"提交修改

4. **手机核验（修改手机号）**
   - 显示原手机号（已脱敏）
   - 输入新手机号
   - 输入登录密码验证身份
   - 点击"确认"提交修改

### 1.2 子功能列表

#### 1.2.1 查看个人信息子功能
- **基本信息展示**（只读）：
  - 用户名
  - 姓名
  - 国家/地区
  - 证件类型
  - 证件号码（脱敏）
  - 核验状态
- **联系方式展示**：
  - 手机号（脱敏，显示核验状态）
  - 邮箱（脱敏，显示激活状态）
- **附加信息展示**：
  - 优惠(待)类型

#### 1.2.2 编辑联系方式子功能
- 进入编辑模式（点击"编辑"按钮）
- 显示"去手机核验修改"链接
- 显示"去安全邮箱修改"链接
- 退出编辑模式（点击"保存"按钮）

#### 1.2.3 编辑附加信息子功能
- 进入编辑模式（点击"编辑"按钮）
- 选择优惠(待)类型（下拉选择）
- 保存修改（点击"保存"按钮）

#### 1.2.4 手机核验子功能
- 显示原手机号和核验状态
- 选择国家/地区代码（默认+86）
- 输入新手机号
- 输入登录密码验证
- 提交修改（点击"确认"按钮）
- 取消修改（点击"取消"按钮）

### 1.3 功能边界

**支持的功能**：
- ✅ 查看所有个人信息（基本信息、联系方式、附加信息）
- ✅ 编辑优惠(待)类型（成人/儿童/学生/残疾军人）
- ✅ 修改手机号（需密码验证）
- ✅ 修改邮箱（需跳转专门页面）
- ✅ 信息脱敏显示（证件号、手机号、邮箱）
- ✅ 核验状态展示（手机号、邮箱、证件）

**不支持的功能**：
- ❌ 修改用户名（注册后不可更改）
- ❌ 修改姓名（核心身份信息不可修改）
- ❌ 修改证件类型和证件号码（需实名认证）
- ❌ 修改国家/地区（与证件信息绑定）
- ❌ 修改核验状态（系统自动核验）

### 1.4 前置条件

- **必须登录**：所有个人信息管理功能均需用户登录
- **账号实名认证**：至少完成基本的实名认证
- **网络环境**：稳定的网络连接
- **浏览器要求**：支持现代浏览器（Chrome、Edge、Firefox等）
- **密码记忆**：修改手机号需要输入登录密码

### 1.5 业务规则

1. **信息安全规则**
   - 证件号码脱敏显示（仅显示前4位和后3位）
   - 手机号脱敏显示（仅显示前3位、国家代码和后4位）
   - 邮箱脱敏显示（仅显示前2位和@后的部分，中间用*代替）

2. **核心信息不可修改**
   - 姓名、证件类型、证件号码添加后不可修改
   - 需修改核心信息需联系客服或到车站办理

3. **手机号修改规则**
   - 必须输入正确的登录密码
   - 新手机号不能与原手机号相同
   - 新手机号未被其他账号使用
   - 修改后需要重新进行核验

4. **优惠类型修改规则**
   - 可随时修改，立即生效
   - 影响后续购票的票价计算
   - 儿童、学生、残疾军人需符合相应条件

## 2. 优先级 (MoSCoW评级)

### 2.1 Must Have（核心功能）

| 功能点 | 评级依据 |
|--------|----------|
| 查看个人信息 | 核心功能，用户必须能查看自己的账号信息 |
| 显示基本信息 | 必须功能，包括用户名、姓名、证件信息 |
| 显示联系方式 | 必须功能，包括手机号和邮箱 |
| 信息脱敏显示 | 安全要求，保护用户隐私信息 |
| 修改手机号 | 重要功能，用户需要能更新联系方式 |
| 密码验证 | 安全要求，防止未授权修改 |

### 2.2 Should Have（重要功能）

| 功能点 | 评级依据 |
|--------|----------|
| 编辑优惠类型 | 重要功能，影响购票价格 |
| 修改邮箱 | 重要功能，用于接收通知和找回密码 |
| 核验状态展示 | 告知用户信息是否通过系统核验 |
| 编辑模式切换 | 提升用户体验，区分查看和编辑状态 |
| 国家代码选择 | 支持国际手机号，扩大用户覆盖 |

### 2.3 Could Have（增强功能）

| 功能点 | 评级依据 |
|--------|----------|
| 添加日期显示 | 帮助用户了解账号创建时间 |
| 最后修改时间 | 记录信息变更历史 |
| 修改历史记录 | 审计和安全追溯 |
| 邮箱激活状态 | 告知用户邮箱是否可用 |

### 2.4 Won't Have（当前版本不考虑）

| 功能点 | 评级依据 |
|--------|----------|
| 修改姓名 | 安全和合规性考虑，核心身份信息不允许修改 |
| 修改证件信息 | 涉及实名认证，需线下办理 |
| 自动保存 | 技术复杂度高，用户明确保存更安全 |
| 信息导出 | 使用场景有限，优先级低 |
| 修改用户名 | 系统设计限制，注册后不可更改 |

## 3. 用户故事 (User Stories)

### 3.1 查看个人信息

#### US-01: 查看个人基本信息

```
As a 已登录用户
I want to 查看我的个人基本信息
So that 我可以确认我的账号信息是否正确

验收条件：
- 能进入"个人中心 > 个人信息 > 查看个人信息"页面
- 页面显示基本信息区，包含用户名、姓名、国家/地区、证件类型、证件号码、核验状态
- 所有基本信息为只读显示
- 证件号码显示脱敏格式（如：4301***********014）
- 核验状态显示"已通过"或"待核验"
```

#### US-02: 查看联系方式

```
As a 已登录用户
I want to 查看我的联系方式
So that 我可以确认手机号和邮箱是否正确

验收条件：
- 联系方式区显示手机号和邮箱
- 手机号显示脱敏格式（如：(+86) 138****7076）
- 邮箱显示脱敏格式（如：24******78@qq.com）
- 显示手机号的核验状态（"已通过核验"）
- 显示邮箱的激活状态（"已激活"）
- 有"编辑"按钮可进入编辑模式
```

#### US-03: 查看附加信息

```
As a 已登录用户
I want to 查看我的优惠(待)类型
So that 我可以了解当前购票使用的票种类型

验收条件：
- 附加信息区显示"优惠(待)类型"
- 显示当前类型（成人/儿童/学生/残疾军人之一）
- 有"编辑"按钮可进入编辑模式
```

### 3.2 编辑联系方式

#### US-04: 进入联系方式编辑模式

```
As a 已登录用户
I want to 点击联系方式的"编辑"按钮
So that 我可以修改我的联系方式

验收条件：
- 点击"编辑"按钮后进入编辑模式
- "编辑"按钮变为"保存"按钮
- 手机号旁显示"去手机核验修改"链接
- 邮箱旁显示"去安全邮箱修改"链接
- 点击"保存"按钮退出编辑模式
```

#### US-05: 跳转修改手机号

```
As a 已登录用户
I want to 通过"手机核验"页面修改手机号
So that 我可以更新我的联系电话

验收条件：
- 点击"去手机核验修改"链接
- 页面跳转到"手机核验"页面（userSecurity_bindTel.html）
- 显示原手机号（脱敏）和核验状态
- 有输入框可输入新手机号
- 有输入框可输入登录密码
- 有"确认"和"取消"按钮
```

### 3.3 编辑附加信息

#### US-06: 修改优惠(待)类型

```
As a 已登录用户
I want to 修改我的优惠(待)类型
So that 我可以购买相应的优惠票种

验收条件：
- 点击附加信息的"编辑"按钮
- "编辑"按钮变为"保存"按钮
- 优惠(待)类型变为下拉选择框
- 下拉框包含4个选项：成人、儿童、学生、残疾军人
- 选择新类型后点击"保存"
- 修改成功，显示新的类型
```

### 3.4 手机核验

#### US-07: 修改手机号 - 正常流程

```
As a 已登录用户
I want to 在手机核验页面修改我的手机号
So that 我可以用新手机号接收服务信息

验收条件：
- 在手机核验页面显示原手机号：+86-138****7076 已通过核验
- 国家代码默认为+86，可点击切换
- 输入新手机号（如：13900139000）
- 输入登录密码
- 点击"确认"按钮
- 系统验证密码和手机号格式
- 修改成功，返回个人信息页
- 个人信息页显示新手机号（脱敏）
```

#### US-08: 取消修改手机号

```
As a 已登录用户
I want to 在手机核验页面取消修改
So that 我可以保留原手机号

验收条件：
- 在手机核验页面填写了部分信息
- 点击"取消"按钮
- 返回个人信息页
- 手机号保持不变
```

### 3.5 异常流程

#### US-09: 修改手机号时密码错误

```
As a 已登录用户
I want to 看到密码错误的提示
So that 我知道需要输入正确的密码

验收条件：
- 在手机核验页面输入新手机号
- 输入错误的登录密码
- 点击"确认"按钮
- 系统提示"密码错误，请重新输入"
- 停留在手机核验页面
- 已输入的新手机号保留
```

#### US-10: 新手机号格式错误

```
As a 已登录用户
I want to 看到手机号格式错误的提示
So that 我可以修正输入

验收条件：
- 在手机核验页面输入格式不正确的手机号（如：12345）
- 输入登录密码
- 点击"确认"按钮
- 系统提示"手机号格式错误，请检查"
- 停留在手机核验页面
- 用户可修改后重新提交
```

## 📊 探索过程总结

### 探索路径

1. **个人中心页** → 进入查看个人信息 → 查看三个信息区
2. **编辑联系方式** → 发现需跳转到专门页面修改 → 点击跳转链接
3. **编辑附加信息** → 点击下拉框 → 查看优惠类型选项
4. **手机核验页** → 查看表单字段 → 了解修改流程

### 关键发现

1. **分区域管理**：个人信息分为基本信息、联系方式、附加信息三个区域
2. **核心信息不可修改**：姓名、证件信息添加后无法在页面修改
3. **独立修改页面**：手机号和邮箱需要跳转到专门页面进行修改
4. **密码验证机制**：修改手机号需要输入登录密码验证身份
5. **信息脱敏显示**：证件号、手机号、邮箱在页面上均显示脱敏格式
6. **优惠类型灵活**：优惠(待)类型可在页面直接修改，支持4种类型
7. **核验状态展示**：显示手机号、邮箱、证件的核验/激活状态
8. **编辑模式切换**：通过"编辑"/"保存"按钮切换查看和编辑模式

### 技术特点

- **前端技术**：使用无障碍模式（ARIA标签），支持键盘导航
- **表单验证**：前端实时验证，必填项提示
- **安全机制**：信息脱敏、密码验证、会话管理
- **用户体验**：编辑模式切换，操作反馈及时，错误提示明确
